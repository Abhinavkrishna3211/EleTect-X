# web/frontend

EleTect public marketing site + ranger/officer/admin dashboard. React 19 + Vite + TypeScript + Tailwind CSS v4 + shadcn/ui + React Router.

Visual spec: match `docs/design-reference/EleTect Platform.dc.html` and `SectorMap.dc.html` pixel-for-pixel.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — type-check and build for production
- `npm run lint` — ESLint
- `npm run format` — Prettier write
